# Citing QpiAI Finance

Cite the version used for the reported financial models or computations. The repository's [CITATION.cff](../CITATION.cff) provides structured software metadata.

For version 1.0.3:

> QpiAI. QpiAI Finance, version 1.0.3. https://github.com/qpiai/qpiai-finance

```bibtex
@software{qpiai_finance,
  author = {{QpiAI}},
  title = {QpiAI Finance},
  version = {1.0.3},
  url = {https://github.com/qpiai/qpiai-finance}
}
```

When computational details matter to a publication, record the financial assumptions, input horizon and units, solver or algorithm, execution settings, and relevant dependency versions with the research methods. A software citation does not replace the mathematical or methodological references for a particular model.
