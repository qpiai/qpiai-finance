QpiAI Finance user manual

QpiAI Finance expresses optimization in financial terms and preserves those terms through quantum-inspired, gate-based, and standard numerical methods. Start with the decision and its constraints, select a supported representation, then inspect the recovered financial result.

Start using the library

Read getting started for installation, financial input preparation, authentication, and a first portfolio workflow. Use data conventions to establish identifier order, units, horizons, dates, and covariance validity. Solver selection and execution explains route selection, options, limits, and verification.

Representations and research controls

Quantum-inspired and gate-based quantum optimization covers portfolio polynomial compilation, native higher-order solving, QUBO and Ising, penalties, samples, algorithm configuration, execution, and recovery. Custom financial models explains reuse of financial calculations, detached model exports, explicit Opt compilation, and verification of added financial rules.

The algorithm control reference lists circuit, optimizer, mixer, initialization, and execution settings. The solver option reference defines local/platform numerical controls and links to the complete native SCIP parameter catalogue.

Shared calculations

Risk analytics covers estimates, factor covariance, risk contributions, Black–Litterman views, VaR, and expected shortfall. Scenarios defines weighted outcomes, paths, sampling, and information trees. Cash flows covers loan schedules, discounting, and present values. Trading costs defines fee and market-impact calculations.

Results and integration

Read results and verification for financial decisions, metrics, tables, statuses, reconciliation, replay, and recorded Opt recovery. Use interchange for supported model, scenario, and result JSON. Plotting provides the Matplotlib API and required result data.

The public API index maps imports to their reference pages. automation.md supplies task selection and execution procedures for automated workflows. Contributing, bug reporting, and feature requests describe project participation. Source is hosted at qpiai/qpiai-finance.
