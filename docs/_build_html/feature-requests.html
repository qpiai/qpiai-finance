Feature requests

Search existing proposals, then use the feature request form.

Describe the financial task and the practitioner who needs it. State the inputs, decision, objective, hard constraints, units, assumptions, and required output. Explain why existing financial models, reusable calculations, or Opt compilation do not cover the task.

Include a proposed public workflow when useful, along with the mathematical formulation, suitable solver classes, expected scale, and a credible reference. For quantum-inspired or gate-based methods, explain the financial interpretation of the encoding, constraint handling, decoding, and required research controls. Distinguish mathematical applicability from measured advantage.

Identify compatibility, documentation, validation, and execution implications, including whether a proposed route can create paid work. Prefer a capability that strengthens the shared financial mathematics over another overlapping modeling system or application framework.
